# REA

Installazione di REA (https://github.com/morluto/rea), Reverse Engineer Anything.

- CLI: `npm install --global rea-agents` (comando `rea`)
- Registrazione per Claude Code: `rea setup --client claude_code --yes`, poi riavviare la sessione
- Il clone sorgente `REA/rea` e' escluso dal repository: `git clone --depth 1 https://github.com/morluto/rea REA/rea`
