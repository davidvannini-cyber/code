Dietro le quinte

Hosting e automazioni

Il sito vive su Cloudflare e non sul tuo computer: il Mac serve solo a pubblicare le modifiche, e dopo si può spegnere. Il codice e le automazioni stanno su GitHub.

Cloudflare (il sito)

  • Worker «tv-vannini»: pagina, admin, /auto, elenco unito, API;
  • KV (archivio): playlist, fonti, canali nascosti;
  • dominio tv.vannini.online con certificato HTTPS;
  • aggiornamento delle liste ogni 6 ore (0 */6 * * *);
  • piano gratuito.

GitHub (il resto)

  • codice, cronologia e punti di ripristino;
  • «Fire TV APK»: costruisce l'app a ogni modifica;
  • «Guida programmi (EPG)»: ogni 2 ore prepara epg.json;
  • le release firetv-latest e epg-latest sono i due file scaricabili.

Le automazioni nel tempo

I limiti del piano gratuito (e cosa significano)

LimiteIn pratica
Tempo di calcolo breveIl sito non «legge» le liste: le unisce come testo. Liste piccole o medie vanno bene; una lista da 11.000 canali può non starci.
Fino a 8 listeIl piano gratuito concede un numero limitato di richieste esterne per aggiornamento.
1.000 scritture al giornoPiù che sufficienti per uso personale (le scritture sono: aggiornamenti delle liste, canali nascosti).
Nessun backup della lista precedenteSe una lista si rompe, si ripristina rimettendo gli indirizzi: i dati veri stanno nelle liste originali.
Nessuna password per guardareL'elenco è pubblico; solo /admin è protetta. Se in futuro serve, si può aggiungere.

Manutenzione: come fare

Le operazioni di tutti i giorni

Aggiungere una lista

  1. /admin → accedi.
  2. In «Liste (fonti)» aggiungi una riga con l'indirizzo.
  3. «Salva e aggiorna»: sotto compare ✓ e il numero di canali.

Più in alto = priorità maggiore.

Aggiungere un canale locale

  1. Apri M3U-PLAYER-WEB/extra.m3u su GitHub e aggiungi due righe: #EXTINF:-1 tvg-chno="18" group-title="Italia",Nome e sotto l'indirizzo.
  2. Salva (commit). Il sito lo legge al prossimo aggiornamento, o subito con «Aggiorna ora».

Nascondere un canale

  1. /admin → «Canali visibili».
  2. Cerca il canale, togli la spunta.
  3. Premi Salva.

Sito e app lo tolgono al prossimo caricamento.

Cambiare l'ordine di priorità

  1. /admin → «Liste (fonti)».
  2. Riordina le righe: la prima è la preferita.
  3. «Salva e aggiorna».

Chi ha già visto un canale può ricordare la vecchia fonte: si cambia a mano con «cambia fonte».

Pubblicare una modifica al sito

  1. Terminale del Mac: cd …/progetti/code && git pull origin main
  2. cd M3U-PLAYER-WEB/cloudflare && npx wrangler deploy
  3. Ricarica la pagina con la ricarica «forte» (capitolo 10).

Alla fine devono comparire «Deployed» e la riga «schedule».

Aggiornare l'app Fire TV

  1. Downloader → l'indirizzo dell'APK (capitolo 8).
  2. Installa, apri, guarda la versione in alto.

Serve solo quando cambia l'app, non il sito.

Aggiornare la guida programmi subito

  1. GitHub → «Actions» → «Guida programmi (EPG)».
  2. «Run workflow».

Altrimenti si aggiorna da sola ogni 2 ore.

Tornare a una versione precedente

  1. Terminale: git checkout punto-stabile-2026-10-19-admin
  2. Oppure in Claude Code: /restore.

Vedi il capitolo 14.

Prima di una modifica importante conviene avere un punto di ripristino: ce ne sono tre, già pronti (capitolo 14).

Punti di ripristino

Tornare indietro in sicurezza

Ogni modifica è registrata. In più, nei momenti in cui tutto funzionava, sono stati salvati dei punti di ripristino stabili: rami del progetto che non vengono mai modificati.

Come tornare a un punto

  1. Nel Terminale, dentro la cartella del progetto: git checkout punto-stabile-2026-10-19-admin (o il nome del punto che vuoi).
  2. Per pubblicare quella versione sul sito: cd M3U-PLAYER-WEB/cloudflare && npx wrangler deploy.
  3. Per tornare all'ultima versione: git checkout main.

Il registro dei salvataggi

Il file REGISTRO-SALVATAGGI.md contiene una riga per ogni modifica: data, versione di partenza, file toccati e il comando per tornare indietro. In Claude Code il comando /restore mostra gli ultimi 20 salvataggi e ripristina quello scelto.

Attenzione all'app. Tornare a un punto ripristina il codice. Il file dell'app già installata sulla Fire TV resta quello che hai installato; per un'app di una versione precedente va ricostruita da GitHub (si può fare dal punto di ripristino).
