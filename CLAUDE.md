# Regole di lavoro (repository code)
- Pubblica direttamente su `main` (push fast-forward, mai force push). Non fermarti sul branch claude/...
- A fine lavoro pubblica senza aspettare che l'utente lo chieda, poi scrivi: "Fatto, fai sync".
- Pull request: se servono, creale comunicando: "Fai sync".
- Dopo ogni pubblicazione aggiungi una riga a REGISTRO-SALVATAGGI.md: data, commit di partenza, file modificati, come tornare indietro (git checkout <commit>).
